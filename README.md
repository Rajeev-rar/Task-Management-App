# Task Management App

A full-stack productivity web application that helps users create, organize, assign, and track tasks efficiently. Designed for individuals and teams to manage daily work with ease.

## 🚀 Features
- User Authentication (Login / Register)
- Create, Edit, Delete Tasks
- Task Status Tracking (Pending / In Progress / Completed)
- Set Priorities and Deadlines
- Responsive Design for Mobile & Desktop
- Dashboard for Better Task Management

## 🛠️ Tech Stack
- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Version Control:** Git & GitHub
